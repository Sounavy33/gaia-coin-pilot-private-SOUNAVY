# Contributing to Gaia Coin (Private Pilot)

Thank you for supporting the Gaia project.

## Scope
This pilot repo is for testing, governance, and review work only. It is not the original production repository.

## Contribution flow
1. Create a feature branch.
2. Add code and tests.
3. Run the relevant tests locally.
4. Open a pull request.
5. Accept the contributor agreement (CLA) in the PR template.

## CLA
All contributors must accept the project CLA before merge. See `CLA.md`.

## Review policy
- Keep changes focused.
- Do not modify the original repo.
- Do not delete or rewrite the backup manifest.
